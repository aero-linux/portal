### 🌐 Overview
The official web documentation portal for **[Aero Linux Developer OS](https://github.com/aero-linux/aero-linux)**. Features an interactive terminal emulator, command-line API reference, ISO installation guides, dual-boot walkthroughs, and developer suite documentation.

### 🚀 Local Development
Serve the static web assets locally using any HTTP server:

```bash
# Using Python 3
python3 -m http.server 8000

# Open in browser: http://localhost:8000
```
